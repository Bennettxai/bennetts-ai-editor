# Starter sounds

Seven short sounds for straightforward edits. Keep them quieter than speech and use them sparingly.

| File | Suggested use |
| --- | --- |
| `click.ogg` | A click or small label appearing |
| `pop.ogg` | A caption/card entering |
| `impact.ogg` | A short low bong for emphasis |
| `confirm.ogg` | A completed step |
| `glitch.ogg` | A quick digital accent |
| `whoosh-1.wav` | A quick movement |
| `whoosh-2.wav` | An alternate movement |

These are general interface and swish effects, not copyrighted meme samples. No background music is bundled. Add music you have permission to use.
