# Bennett Legacy

A restrained Monolith theme: dark surfaces, off-white type, fine borders and simple labels.

| Role | Color |
| --- | --- |
| Background | `#0a0a0a` |
| Raised surface | `#141414` |
| Text | `#f2f2f2` |
| Secondary text | `#9c9c9c` |
| Border | `#242424` |

Use a system sans-serif for titles and captions, monospace for small labels. No font download is required. Keep animations simple: brief fades, small scale changes, hard cuts. Keep the speaker recognizable and titles brief.

Palette reference: the public [FounderOS Legacy Monolith theme](https://github.com/Bennettxai/FounderOS/blob/main/app/globals.css). This starter implements its own basic video layout; it does not include the platform UI.

The Bennett Legacy name identifies this starter. When adapting the template for your own brand, replace the visible label and palette.
